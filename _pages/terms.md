## 1. 적용 범위

Alfred 는 제작자 본인이 개인적으로 사용하려고 만들어 직접 운영하는 비공개
도구입니다. 일반에 배포하거나 서비스로 제공하지 않으며, 제작자 외의 이용자를 받지
않습니다. 이 약관은 해당 사용에 적용됩니다.

## 2. 제공 범위

Alfred 는 Slack 을 통해 대화하고, 사용자가 연결을 허가한 Google 캘린더와 Google
Tasks 를 조회·변경합니다. 접근 범위와 데이터 처리는
[개인정보처리방침](/privacy.html)에 따릅니다.

## 3. 이용자의 책임

- Google 계정 연결은 사용자가 직접 허가하며, 언제든 해제할 수 있습니다
- 일정·할 일의 변경과 삭제는 사용자의 지시에 따라 수행됩니다. 삭제는 사용자의
  확인을 거친 뒤에만 실행됩니다
- 사용자는 자신의 계정 자격증명을 안전하게 관리할 책임이 있습니다

## 4. 보증의 부인

Alfred 는 있는 그대로 제공되며, 특정 목적에의 적합성이나 무중단 동작을 보증하지
않습니다. 답변 생성에 대규모 언어 모델을 사용하므로 결과가 부정확할 수 있습니다.
중요한 일정과 결정은 사용자가 직접 확인해야 합니다.

## 5. 책임의 제한

법령이 허용하는 범위에서, Alfred 의 사용 또는 사용 불능으로 발생한 손해에 대해
제작자는 책임을 지지 않습니다.

## 6. 변경

이 약관은 예고 없이 변경될 수 있으며, 변경 내용은 이 페이지에 게시됩니다.
